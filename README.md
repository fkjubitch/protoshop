# Protoshop - 简易绘图程序

这是一个小巧的简易绘图程序，作为我的第一次计算机图形学大作业。这个名字是怎么由来的呢？首先 Photoshop 是著名的平面设计软件，拥有强大的绘图功能，而 proto- 前缀又有“原始的”的意思，所以这个名字意为“最原始的Photoshop”或者“经费不足版Photoshop”。Protoshop 还有数不清的不足与Bug，需要进一步改进和完善，欢迎提交 pr 帮助改进。目前只支持 Windows 系统。

## 主要功能

1. 部分基本图形绘制（任意画笔、线段、矩形、多边形、圆、椭圆）
2. 图形选择（仅矩形方框选择）
3. 图形变换：图形平移、图形缩放（尚不支持多边形）、图形旋转、多边形节点调整
4. 图形着色（包括边框着色与填充着色）
5. 从调色盘选择颜色
6. 边框类型选择：实线、虚线、点线、划-点交替线
7. 调整线框宽度（1~50px）
8. 鼠标坐标位置显示
9. 画布扩展：通过图形缩放可以将画布扩大
10. 文件保存：可以保存画布为 PNG 图片，也可以导出为 JSON 以便下次打开使用
11. 撤销与重做：可以撤销或重做在画布上的行为
12. 快捷键：详见“帮助→快捷键”
13. 窗口自适应
14. 新增：
    - 切换图形绘制方式：在“绘图→绘制方式”中，可以选择“自制光栅”和“调库函数”两种绘制方式，前者是不依赖重要的库函数自己实现的绘图方式，后者是依赖重要库函数实现的绘图方式。当前绘图方式的选择在左下角会显示。
    - 对比不同算法：在“自制光栅”绘图方式下，绘制直线、圆形和椭圆可以选择不同的算法（如Bresenham。DDA，中点圆等）。

## 开发环境

Windows 10及以上, QtCreator, Qt 6.9, MinGW 64, C++ 11及以上, CMake 3.31（推荐）

## 如何使用

### 1. 直接下载.exe可执行文件

在右边的 Releases 下载打包好的可执行文件。

### 2. 下载源码，本地编译

下载源码

```bash
git clone https://github.com/fkjubitch/protoshop.git
```

在 QtCreator 中点击打开项目，选择 CMakeLists.txt 打开，为项目配置 Qt6 套件即可。

## 示例文件

在 "jsonexample" 文件夹中，有两个子文件夹，分别为 lib 和 raster。lib 文件夹中的 json 文件只可以导入到“调库函数”方式中，raster 文件夹中的 json 文件只可以导入到“自制光栅”方式中。

## 目前发现的问题

1. 有小概率情况会崩溃
2. “调库函数”方式中，旋转后进行缩放会漂移
3. “调库函数”方式中，第一笔的开始点位于左上角(0,0)
4. “调库函数”方式图层混乱
5. 撤销与重做的Bug

## 注意事项

1. 两种绘图方式生成的 JSON 文件不能交叉导入，否则会导入无效。
2. “调库函数”方式中的导出图片是以整个画布为准导出，而“自制光栅”导出的图片则以显示在用户面前的画布大小为准。
